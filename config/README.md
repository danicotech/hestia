# config

設定的結構定義與載入。放在 `internal/` 外面是刻意的:它只有型別和載入邏輯,沒有業務語意,`cmd/` 與 `e2e/` 都要用。

```text
config.go     結構定義、預設值、驗證
*.yaml        各環境的非機密設定
```

## 兩條規則

**機密只走環境變數,不進版控。** yaml 裡放的是逾時、連線池大小、功能開關這類看得到也無所謂的東西。

**啟動時就驗完。** 缺 `PLATFORM_JWT_SIGNING_KEY` 要在啟動的第一秒失敗,不是等到第一個使用者登入才 panic。設定錯誤是唯一適合讓程式直接死掉的錯誤類型。

變數前綴一律 `PLATFORM_`,不用 `HESTIA_`。代號只活在開發者之間,log 和維運看到的東西一律白話。
